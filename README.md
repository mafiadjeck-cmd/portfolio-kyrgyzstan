# Mafiacjeck — портфолио

Полноэкранный сайт-портфолио цифрового дизайнера и разработчика из Кыргызстана.
Ориентирован на клиентов из Кыргызстана и СНГ.

## Что внутри

- адаптивный одностраничный интерфейс;
- видеофон и пиксельная типографика;
- мобильное меню с анимацией;
- ссылки на GitHub, Telegram, Instagram и WhatsApp;
- услуги по дизайну и разработке от 5 000 сом.

## Запуск

Требуется Node.js 22.13 или новее.

    npm install
    npm run dev

Проверка production-сборки:

    npm run build
